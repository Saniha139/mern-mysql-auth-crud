# MERN MySQL Auth CRUD

## Features
- User Register & Login (JWT)
- Add, View, Delete Items
- MySQL Database Integration

## Backend Setup
cd backend
npm install
node server.js

## Frontend Setup
cd frontend
npm install
npm run dev

## API Endpoints
- POST /register
- POST /login
- GET /items
- POST /items
- DELETE /items/:id
